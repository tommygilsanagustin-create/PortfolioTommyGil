# Tommy Gil Game Portfolio

Portfolio personal interactivo para Tommy Gil San Agustin, desarrollado como una experiencia web tipo videojuego 2D.

## Ejecutar

No requiere instalacion de dependencias.

Opcion directa:

1. Abre `index.html` en el navegador.

Opcion con servidor local:

```bash
npm run dev
```

Luego abre:

```text
http://localhost:5173
```
